Buying guides

Save the original product link

When comparing LoveGoBuy finds, record the original Weidian, Taobao or 1688 listing and its item ID. Save one row per size and colour combination. If two listings use the same photos, compare their option menus and size charts separately.

Compare measurements and QC photos

Measure a piece you already wear. For shoes, check insole length in centimetres. For hoodies and jerseys, compare chest width and body length. For trousers, note the waist, rise and inseam. In warehouse quality-control (QC) photos, look for the size tag and ask for a ruler photo if a measurement is unclear.

Build a shipping checklist

Log the parcel weight and box dimensions before comparing quotes. Check whether the carrier bills by actual or volumetric weight. Record the estimated total alongside the return deadline so you can resolve any inspection issue before dispatch.

What to put in each spreadsheet row

Source
Original marketplace link, seller, item ID and date checked.
Variant
Exact colour, size, size chart and your target measurements in centimetres.
Inspection
Photos reviewed, visible issues and any extra angles or measurements requested.
Order cost
Item amount and currency, domestic delivery, fees and estimated international shipping.
Status
Shortlisted, ordered, awaiting inspection or dispatched, with the return deadline where available.

Frequently asked questions

What is a LoveGoBuy spreadsheet?

It is a list of shopping finds that pairs product links with notes such as size, colour, seller and quality-control photos. This independent guide offers a sample worksheet and links to CAFANS categories.

How do I tell whether a product link is current?

Open the original listing and check the seller, item ID and availability of the exact size and colour you saved. Record the date you checked it so you know when to verify it again.

Can QC photos establish authenticity?

QC photos help you assess visible condition, measurements and the selected variant. For authenticity, look for seller documentation and qualified authentication where appropriate.

What should I include in my shipping budget?

Include the item price, domestic delivery, applicable service fees, international shipping and any applicable taxes or duties. Confirm the actual charges and the carrier's billable weight before paying.
